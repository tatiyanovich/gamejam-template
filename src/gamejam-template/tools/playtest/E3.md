# E3 — Neighbour paw animation

`NeighbourView` lives on both D11 neighbour prefabs and reacts to the existing
`INeighbourQuery.OnPawChanged` and `ITeacherQuery.OnAttentionChanged` events. The world views keep
the authored shoulder pivots and mirrored Fluffy root; no presentation state is added to ECS.

| Trigger | Motion |
|---|---|
| Matching meow | Head jolts and the paw moves `+0.4` units / `+70°` in `0.25` s with `OutBack` |
| Repeated meow | Head jolts again and the paw window restarts without stacking |
| Last second | Raised paw shakes by `±3°` while the existing radial ring drains |
| Window expires | Paw returns over the answer in `0.35` s and the ring hides |
| Teacher watches | Both neighbours lower their heads into their papers until she looks away |

`CopycatArtBuilder.BuildNeighbourViews` adds and wires the view without rebuilding unrelated D11
assets. The full D11 neighbour build uses the same helper, so later art rebuilds keep E3.

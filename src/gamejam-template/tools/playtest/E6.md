# E6 — Impact feedback

E6 reuses the existing camera-shake pipeline and the B7 HUD views instead of introducing new ECS
presentation state.

| Trigger | Feedback |
|---|---|
| Answer copied | The answers counter punches to `1.22×` and returns over `0.32` s using unscaled time |
| `ExamOutcome.Caught` | `GameplayWindow` sends one `Default` camera-shake request |
| `ExamOutcome.Caught` | The danger vignette flashes red to `0.85` alpha and fades out over `0.55` s |
| Report Card open | The grade stamp waits `0.28` s, slams from `2.2×`, then settles with a short punch |

The counter animation limits the amount of elapsed time consumed by one frame, so a hitch cannot
skip the entire feedback beat. Closing or reopening either window resets its transient animation.

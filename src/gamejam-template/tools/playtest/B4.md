# B4 — Contextual tutorial hints

Five phase-one hints from `GDD §11`, strings from `GDD §13.4`. Each one disappears once the
player performs the action and never returns during the attempt.

Domain: the sticky flags `TutorialMeowed`, `TutorialLeaned`, `TutorialDodgedTeacher` and
`TutorialDuckThrown` live on `ExamRun`; one `Mark*` system per trigger maintains them
(meow event, held lean, teacher facing the class while upright, duck thrown event).
`UpdateTutorialHintSystem` derives the single `TutorialHint` value from those flags,
`AnswersCopied`, the readable answer and the question index (3 for the turn hint, 5 for
the duck hint). A finished attempt always resolves to `None`.

View: `IExamQuery.OnTutorialHintChanged` feeds `GameplayWindow.HandleHint`, which picks the
final string, resizes the bubble (112 without glyphs, 160 with) and shows the D6 stroke
glyphs for the copy hint. Hint one falls back to `Press M to get Whiskerstein's attention!`
when no microphone device is present. `COPYCAT/Art/Build B3 Gameplay Window` rebuilds the
bubble at (560,472,560,112) above the player desk, clear of the kitten, teacher and neighbours.

The arrows in hint three are sprites, not glyphs: none of the four project fonts contains
U+2190..U+2192, so the string is split into `Copy the strokes:` plus the existing
`glyph_arrow_{left,up,right}_normal` images (see D‑78).

# B5 — Report Card

`COPYCAT/Art/Build B5 Result Window` rebuilds `Content/UI/Result/ResultScreen.prefab` from the D8
`report` layout: paper panel, heading, teacher line, grade stamp, three stars, five stat rows,
`TOP COPYCATS` table with ten rows, own-rank line, personal best and the two buttons.

`GameplayWindow` opens the window 1.6 seconds after the exam finishes — after the teacher's final
line has been read — and closes the HUD, so only the classroom stays behind the card. `RETAKE EXAM [R]`
restarts the Exam branch, `MAIN MENU` goes to `StartLaunch`; `R` does the same as the first button.

The grade table and the star tiers live in `IExamGradeService`; the window maps them to the baked
`stamp_grade_*` sprites, the `GDD §12` messages and `star_filled`/`star_empty`. Stats come from
A15 queries: answers/total/time/meows from `IExamQuery`, almost caught from `ITeacherQuery`,
duck throws from `IDuckQuery`, personal best and the player name from `IProgressQuery`.
The result is submitted once per opened card through `ILeaderboardService`; while the request is in
flight the table shows `Sending your result…`, and any failure or missing connection shows
`Leaderboard offline` with the rows hidden.

`CAUGHT 😾` and `BELL RANG 🔔` lost their emoji (D‑80): none of the three project fonts contains
U+1F63E or U+1F514, so the glyphs would have rendered as missing-glyph boxes.

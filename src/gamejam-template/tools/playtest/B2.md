# B2 — Attendance

`COPYCAT/Art/Build B2 Attendance Window` rebuilds the prefab, config and UI Addressables entry.
The config inherits the existing `window_configs` folder label. Rebuild B1 separately for the menu.
PLAY opens Attendance only for an empty saved name; START EXAM saves through ProgressFactory,
waits a frame for the snapshot pipeline and fades into Exam. Repeated clicks are locked.

The input accepts 12 ASCII letters/digits; empty input uses `Nameless Kitten`.
The meter reads IMeowQuery events, its marker uses MeowConfig.ThresholdLevel.
20–40% for 0.5 seconds shows LOUDER; microphone MeowEvent latches LOUD ENOUGH and a checkmark.
FromMicrophone preserves short pulses across the event pipeline's one-frame delay and excludes M.
Missing microphones show a gray meter and `No mic — press M to meow`; starting is always available.
Device availability comes directly from IMicrophoneService, including changes while the window is open.

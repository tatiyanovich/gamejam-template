# E4 — Duck throw animation

`DuckView` reacts to the existing `IDuckQuery.OnStateChanged` event and keeps presentation state
out of ECS. The D7 prefab now owns the view, its four authored frames, a world-space landing-dust
burst, and a local audio source for the procedural squeak.

| State | Presentation |
|---|---|
| `OnDesk` | Idle frame bobs by `0.06` units over the authored `1.2` s cycle |
| `Flying` | `0.6` s quadratic arc through the D7 apex, `720°` rotation, and `0.1` s frame swaps |
| `OnFloor` | Lands at the authored floor point, punches scale, emits eight dust particles, and squeaks |
| `Carried` | Attaches to Mrs. Hisskins's paw and follows her existing return walk |
| `OnDesk` after carry | Detaches and eases back to the original desk position |
| `Confiscated` | Uses the sad frame at the authored teacher-desk position after the third throw |

`CopycatArtBuilder.BuildDuckView` adds and wires the view without rebuilding unrelated D7 assets.
The full D7 duck build calls the same helper, so later art rebuilds retain E4.

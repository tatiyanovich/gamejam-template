# E2 — Kitten animation

`KittenView` (`Assets/Code/Gameplay/Input/Behaviours/KittenView.cs`) is attached to the D11
`Kitten` prefab and switches its authored poses from the existing input, exam and teacher queries.
It preserves the seven-pose rig produced by `art/src/d3/rig.json`; the builder wires the same pose
array whenever D11 prefabs are rebuilt.

| Trigger | Motion |
|---|---|
| Idle | Body scale `1↔1.02` and tail rotation `−10↔+10°`, both on a 1.6-second loop |
| Hold SPACE | Back view swaps to the current neighbour profile, then moves `±0.6` units and rotates `±12°` in 0.2 seconds |
| `TeacherAttention.Watching` while leaning | Matching panic profile replaces the normal profile, with the authored wide eyes and small pupils |
| Correct answer progress while leaning | Right paw rotates `0→−15→0°` in 0.12 seconds |
| Release SPACE | Idle back view is restored |

`LeanHeld` is `Watched`, so `InputQuery.OnLeanChanged` notifies the view in the same query pass as
the other HUD/world views. `InputWatchedCleanupSystems` runs after query notification. No player
entity or animation system was reintroduced: the kitten remains the static desk presentation from
D-19.

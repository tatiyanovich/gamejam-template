# B1 — Launch menu

The embedded form described below was replaced by the separate [B2 AttendanceWindow](B2.md).
B1 verification below records the original implementation; current builds use B2 for first-time sign-in.

`LaunchWindow` uses the existing window config/address and D8 sprites with D2 background layers.
`COPYCAT/Art/Build B1 Launch Window` rebuilds its prefab without touching D11 or Gameplay.
The 1920×1080 composition fits the available window while preserving proportions.

PLAY reads `IProgressQuery`: an empty/whitespace name opens the embedded `AttendanceSheet`;
a saved name goes directly through the existing fade/camera/core-loop transition to Exam.
The basic form accepts up to 12 ASCII letters/digits. Empty input uses the GDD placeholder
`Nameless Kitten`. START EXAM sends name and save requests through `ProgressFactory`;
`SetPlayerNameByRequestSystem` runs before snapshot saving and the node transition.
Null names from saves are normalized before creating the progress entity, because generated
`ReplacePlayerName` compares against the current value using `.Equals`.

B2 remains open: extract the form into `AttendanceWindow`, add microphone meter/calibration
and MIC CHECK feedback. B6 owns the intro. The current form does not gate starting on a microphone.

Button subscriptions are scoped to window open/close. Controls lock during a transition.
QUIT calls `Application.Quit()` in players and exits Play Mode in the editor.
The menu requires the cursor and ignores window-back dismissal.

# F1–F4 audio

## Content

- Source recordings used from `sounds/`: `meow_3.mp3`, `duck.mp3`, `error_4.mp3`, `paper_writing.mp3`, `reaction_1.mp3`, `heartbeat_2.mp3`, `school_ring.wav`, `ingame_1.wav`, `tention_1.mp3`.
- Generated where no fitting source existed: duck throw/landing, stamp, clock tick, footsteps, class laugh, time warning and UA `Lesya` intro dub.
- Intentionally unused: menu, minigame, success, win and generic fail tracks.
- Output: 17 effect WAV files, two 60 s music loops and four intro VO WAV files under `Assets/AddressableResources/Content/Audio`.

## Rebuild

1. From the repository root run `python3 art/audio/build.py` on macOS with ffmpeg/ffprobe and the `Lesya` voice installed.
2. In Unity run `COPYCAT → Audio → Build F1-F4`.
3. Enter Play Mode and run `COPYCAT → QA → Test F1-F4 audio`.

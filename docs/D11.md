# D11 — импорт и сборка Unity

D2–D8 интегрированы в `Assets/Scenes/Gameplay.unity`. Исходники и раскладки остаются в `art/`; Unity-ассеты — в `Assets/AddressableResources/Content/`. Это сборка арта: события ECS, динамические вопросы/ответы, HUD и анимации подключаются в A15/B3/E1–E4. Поля динамического текста пустые; данные демонстрационных экзаменов в сцену не перенесены.

Это рендеры Unity, не SVG-макеты. В проверке поз состояния переключены вручную через MCP; заливки в проверочных кадрах иллюстративные.

## Импорт

95 PNG: D2 — 9, D3 — 12, D4 — 12, D5 — 8, D6 — 22, D7 — 5, D8 — 27. PNG побайтно совпадают с экспортами.

- Sprite Single, Full Rect, без trim: отдельные PNG уже разделены на слои. Поля сохраняют совмещение сменных поз.
- @2x → PPU 200; `vignette_radial` @1x → PPU 100; `icon_app` — Default texture и иконка Player Settings.
- Bilinear, Clamp, no mipmaps, no NPOT scaling, Uncompressed, max size 4096: фон 3840 px не уменьшается.
- Pivot = `(px/width, 1-py/height)` из соответствующего `layout.json`/`rig.json`.
- UI 9-slice borders = 64 texture px (32 reference px); Canvas reference PPU 100.
- Patrick Hand, Nunito Bold и Luckiest Guy импортированы с лицензиями в `CopycatShared/Fonts`. TMP SDF — dynamic, ASCII и используемая пунктуация прогреты, дополнительные атласы разрешены.

## Сборка и дальнейшая привязка

В Gameplay корень `CopycatArt`; под ним nested prefabs. Парты соседей содержат собственные листы и передают им поворот ±12°. Fluffy зеркалится только корнем. На сцене камера не дублируется: существующий ECS создаёт `CameraView`, orthographic size = 5.4 для кадра 19.2×10.8 units.

- `Kitten/idle` активно по умолчанию; остальные имена совпадают с `rig.poses`. Голова каждой позы содержит уши и глаза. Для E2 выбирать активную позу, а дыхание/движение лап/хвоста применять к её узлам.
- У Teacher по умолчанию `writing`; `staring` уже имеет наклон/scale, варианты взгляда — голову/белки/зрачки/очки, chalk — плечевой pivot. SortingGroup позиции writing/turning = 8, watching/staring = 12, чтобы учительница обходила стол.
- `Whiskerstein/Paw` и `Fluffy/Paw`: закрытая локальная позиция `(-1.25,3.95,0)`; поднятая — Y +0.4, Z +70°, до масштаба/зеркалирования корня. E3 задаёт время/easing из D5. Тело 18 → парта 20 → лист 22 → лапа 23 → голова 24 → глаза 25/26.
- `PlayerPaper`: `header`, `student`, `question`, `answerLabel`, `Answer`, `AnswerGlyphs`, неактивный `stamp_copied`. B3 обновляет динамические строки и содержимое ответа из ExamConfig/queries.
- `NeighbourPaper`: `StudentName`, `Word`, `Pick1..4`, `StrokeGlyphs`, неактивный круг Pick. Имена соседей записаны overrides на сцене; вопрос/ответ пустые.
- `PawTimer`: внешний Transform несёт положение и scale 0.5, дочерний world-space Canvas — перевод px→units 0.01. `ring_timer` — Image Filled, Radial360, Top, clockwise; B3/E3 задаёт `remaining/PawWindow`.
- `Duck`: `duck_idle` активно; остальные кадры неактивны. E4 задаёт путь/смену кадров/конфискацию из D7.
- UI-префабы — заготовки для существующей оконной системы, не новые окна. YellowButton использует SpriteSwap. B1 собран отдельно в LaunchWindow: подписи/обработчики, ButtonLabelOffset и три состояния D8; `COPYCAT → Art → Build B1 Launch Window` воспроизводит меню и базовую форму AttendanceSheet. Rebuild D11 не перезаписывает LaunchWindow. Метры используют Image.Filled. Положение/ширину линии порога MEOW задаёт B3 из текущего микрофонного адаптера; середина в префабе — слот, не игровой порог.

Регистрация `GreyboxFeature` и `GreyboxBoardFactory` снята. Исходники временной фичи и её generated-компонент оставлены для параллельной работы A10; удалять их можно после перехода на B3. До A15/B3/E1–E4 арт в игре статичен.

## Повторение

`Assets/Code/Editor/Art/CopycatArtBuilder.cs`:

- `COPYCAT → Art → Build D11`: копирует PNG и шрифты, применяет импорт, собирает все префабы, группы и Gameplay.
- `COPYCAT → Art → Rebuild D11 Prefabs`: пересобирает только префабы/сцену/группы из уже импортированных ресурсов.

Обе команды запускаются вне Play Mode, открывают Gameplay и заменяют созданные ими префабы и корень `CopycatArt`. После ручной привязки B3/E обновить builder перед повторной сборкой, иначе привязки на генерируемых префабах будут заменены. Остальные корни сцены сохраняются.

Для MCP `Unity_RunCommand`:

```csharp
using System;
internal class CommandScript : IRunCommand
{
    public void Execute(ExecutionResult result)
    {
        Type builder = Type.GetType("Code.Editor.Art.CopycatArtBuilder, Assembly-CSharp-Editor");
        builder.GetMethod("Build").Invoke(null, null);
        result.Log("D11 complete");
    }
}
```

D9/D10 ещё не созданы и не входят в этот импорт; их подключение производится при выполнении соответствующих задач.

## Проверки

`npm run check` прошёл для D1–D8; 95 импортированных PNG совпали с оригиналами. В Unity проверены настройки текстур, отсутствие missing scripts/sprites/fonts в 15 префабах и их Addressables entries. Сборка Addressables для OSX прошла. Проверены рендеры 1920×1080/480×270, смена поз и UI, Boot → Launch → Exam и три рестарта.

При рестарте обнаружен прежний дефект выгрузки: `SceneLoadService` пропускает выгрузку последней сцены, а `RunSessionState` удалял её из реестра. Теперь последняя загруженная сцена остаётся зарегистрированной и используется существующей веткой повторного входа `PreloadSessionState`; ECS попытки пересоздаётся. Это предотвращает накопление копий класса. Проверка: один `CopycatArt` и тот же handle Gameplay после трёх рестартов.

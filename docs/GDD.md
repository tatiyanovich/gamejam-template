# COPYCAT — Game Design Document

**Версия:** 1.0 (5 сентября 2026) · **Тема джема:** Cheat to Win! · **Обязательный элемент:** резиновая утка
**Платформы:** Windows x64, macOS (Universal) · **Сессия:** 1–2 минуты на попытку, 4–6 попыток на игрока
**Весь текст в игре — английский.** Единственное исключение — украинский дубляж интро (P1).

> Предыдущая версия (по HTML‑прототипу) лежит в `docs/prototype/COPYCAT_GDD_v0_prototype.html`.
> Этот файл — единственный источник правды по дизайну. Меняем числа — меняем здесь (см. правило `docs-maintenance`).

## 1. Питч

Ты — котёнок на выпускном экзамене Cat Academy. Ты не выучил ничего. Соседи выучили всё, но
прикрывают ответы лапой. Коты общаются мяуканьем — чтобы сосед поднял лапу и показал ответ,
надо **громко мяукнуть в настоящий микрофон**. Проблема: правило №2 на доске — **NO MEOWING**.
Учительница миссис Хисскинс оборачивается всё чаще. Единственный друг — резиновая утка на парте.

**Core fantasy:** «Я нагло списываю у всех на глазах и выкручиваюсь».
**Главная шутка:** игроку приходится реально громко мяукать в комнате, чтобы играть.

## 2. Дизайн‑столпы

1. **Cheating is the verb.** Списывание — единственный способ ответить. Честно ответить нельзя.
2. **Голос — контроллер.** Без мяуканья игра не идёт: сосед не покажет ответ. Микрофон обязателен, `M` — только аварийный фолбэк.
3. **Читаемый риск.** Игрок всегда знает, куда смотрит учительница, сколько подозрения, сколько открыт ответ.
4. **Быстрая смерть, быстрый рестарт.** Попытка 1–2 минуты, рестарт одной кнопкой, интро не повторяется. Мастерство приходит к 4‑й попытке.

## 3. Игровой флоу

```
Main Menu ──Play──▶ Attendance Sheet (имя + тест микрофона, один раз)
                          │
                          ▼
                  Intro Comic (один раз, Skip по клику/Esc)
                          │
                          ▼
                     EXAM (геймплей)
                     │          │
                  CAUGHT      BELL / PASSED
                     └────┬─────┘
                          ▼
                Report Card (оценка, статы, лидерборд)
                   │ Retake exam ──▶ EXAM (без интро)
                   │ Main Menu ────▶ Main Menu
```

- **Main Menu:** логотип, кнопки `PLAY`, `QUIT`. Утка сидит на углу меню и пищит по клику (пасхалка, P2).
- **Attendance Sheet:** «Sign the attendance sheet»: поле имени (≤12 символов, латиница/цифры), индикатор
  микрофона с порогом и подпись `Meow to test your mic` → при успешном мяуке ставится галочка `LOUD ENOUGH!`.
  Кнопка `START EXAM` активна всегда (микрофон может не быть — тогда игрок увидит подсказку про `M`).
  Имя сохраняется; повторно окно не показывается.
- **Intro Comic:** 5 панелей, ~25 секунд, см. §14. Показывается один раз (флаг в сейве). Пропуск — клик/Esc/Space.
- **Report Card:** см. §12.

## 4. Управление

| Действие | Ввод | Примечание |
|---|---|---|
| Мяукнуть | **Микрофон** (громкость выше порога) / `M` фолбэк | Порог такой, что обычная речь не срабатывает (§8) |
| Наклониться (списывать) | **Удерживать `SPACE`** | Пока не наклонился — ввод ответа не засчитывается |
| Ввод ответа: Strokes | `← ↑ → ↓` или `W A S D` (физические клавиши) | Работает на любой раскладке |
| Ввод ответа: Pick | `1` `2` `3` `4` | Соответствуют вариантам A B C D |
| Ввод ответа: Word | Буквы `A–Z` (физические клавиши) | Слова никогда не содержат `M` и `Q` |
| Бросить утку | `Q` или клик по утке | Только когда утка на парте |
| Пропустить интро | Клик / `Esc` / `Space` | |
| Рестарт с Report Card | `R` или кнопка | |

Мышь нужна только для меню и утки. Геймпад не поддерживается.

## 5. Core loop одного вопроса

1. На своём листе появляется вопрос (флейвор, читать не обязательно) и пустая строка ответа `Answer: ____`.
2. Сосед (левый или правый) прикрывает ответ лапой. Стрелка‑подсказка показывает, у кого ответ.
3. Игрок **мяукает** → сосед поднимает лапу на **окно N секунд** (зависит от фазы, §11). Над соседом тает кольцо‑таймер.
4. Игрок **зажимает SPACE** — котёнок наклоняется к соседу, лист соседа приближается и становится читаемым.
5. Игрок **вводит ответ** согласно типу вопроса (§6). Правильный ввод подсвечивается зелёным на листе соседа
   и одновременно «пишется» на своём листе.
6. Ошибка ввода = **треск карандаша**: `+8` подозрения, элемент мигает красным, с фазы 3 учительница оборачивается.
7. Ответ завершён → штамп **COPIED ✓** на своём листе, `+1` к счётчику, пауза 0.6 с, следующий вопрос.
8. Всё это время учительница по расписанию оборачивается (§9). Наклон под её взглядом наполняет подозрение (§10).

Ритм, который мы хотим: **мяу → наклон → 2–4 нажатия → отпустить SPACE → выждать разворот → снова**.

## 6. Типы вопросов (механики списывания)

Три типа. Тип вопроса задан таблицей контента (§13), а не рандомом, чтобы кривая обучения была предсказуемой.

### 6.1 Strokes (стрелки) — «скопируй начертание»
- Лист соседа: ряд из 2–6 стрелок в квадратиках (как в прототипе). Фикция: коты пишут «лапописью», и ответ — последовательность штрихов.
- Ввод: стрелки/WASD в порядке. Верный штрих — квадрат зеленеет. Ошибка — текущий квадрат мигает красным, прогресс **не** сбрасывается.
- Длина по фазе: 2–3 → 3 → 4 → 5 → 6.

### 6.2 Pick (тест A/B/C/D) — «подсмотри, что обвёл»
- Лист соседа: четыре варианта `A B C D` (короткие смешные слова), один обведён карандашным кругом.
- Ввод: одно нажатие `1–4`. Верно — сразу COPIED. Ошибка — `+8`, круг у соседа на 0.4 с исчезает (надо снова вглядеться), потом появляется.
- Самый быстрый тип. Хитрость с фазы 3: обведённый круг **бледный** и заметен только в наклоне.

### 6.3 Word (слово) — «перепиши слово»
- Лист соседа: слово из 3–6 букв крупным рукописным шрифтом (`TUNA`, `PURR`, `CATNIP`).
- Ввод: буквы по порядку (физические клавиши, раскладка не важна). Верная буква появляется на своём листе.
- Ошибка — `+8`, буква у себя мигает красным и стирается. Слова никогда не содержат `M` и `Q` (хоткеи мяу и утки).

Хоткеи `M` и `Q` действуют всегда. Космос — только наклон. Конфликтов нет, т. к. типы не смешиваются в одном вопросе.

## 7. Соседи

- Два соседа: **Whiskerstein** слева (в очках, ботан) и **Fluffy** справа (огромный пушистый, сонный). У кого ответ — задано в таблице контента; первые три вопроса — только слева.
- По умолчанию сосед **прикрывает ответ лапой**. Поднимает её только на мяу (§8) на время `PawWindow` (§11).
- Во время окна над соседом тает круговой таймер. За 1 с до конца лапа начинает опускаться (телеграф).
- Если окно закрылось на середине ввода — прогресс ввода **сохраняется**, нужно просто мяукнуть ещё раз.
- Соседи реагируют анимацией: на мяу — вздрагивают и поднимают лапу («Huh?»), при взгляде учительницы — утыкаются в лист.

## 8. Мяу (микрофон)

**Зачем мяукать (фикция):** коты глухи к шёпоту и заняты экзаменом; только громкое «MEOW!» заставляет соседа поднять голову и лапу.
**Почему это рискованно:** правило №2 — NO MEOWING. Учительница слышит мяу и с растущей по фазам вероятностью оборачивается.

### Детекция
- Метр громкости 0–100 % = `min(100, RMS × 420)` (как в прототипе, калибруется в Attendance Sheet).
- Порог **40 %**. Красная линия на метре — порог. Триггер по **восходящему фронту**; перевзвод, когда уровень упал ниже **30 %** (75 % от порога).
- Жёсткий кулдаун между мяу **0.7 с** (антиспам, мяу не «стакается»).
- При уровне 20–40 % на 0.5 с показываем подсказку **`LOUDER!`** — игрок понимает, что микрофон работает, но тихо.
- Микрофон недоступен/запрещён → метр серый, подпись `No mic — press M to meow`. Игра играбельна на `M`.

### Эффекты одного мяу
| Условие | Эффект |
|---|---|
| Всегда | Сосед с ответом поднимает лапу на `PawWindow` секунд (окно **перезапускается**, не суммируется) |
| Учительница спиной | С вероятностью `MeowAlert` (по фазе) она разворачивается через 0.8–1.5 с (`Did someone MEOW?`) |
| Учительница уже смотрит на класс | `+15` подозрения, взгляд продлевается на 1.0 с (`NO. MEOWING.`) |
| Во время броска утки (класс ржёт) | Ничего лишнего — мяу тонет в смехе (безопасное мяу) |

Мяу **не снижает** подозрение (было в прототипе, убрано — нелогично). Единственный способ снизить подозрение — не наклоняться (§10) и утка (§10.1).

## 9. Учительница (Mrs. Hisskins)

Состояния и переходы:

| Состояние | Визуал | Что происходит |
|---|---|---|
| **Writing** | Спиной, пишет на доске, мел стучит | Безопасно. По таймеру `CheckDelay` → Turning |
| **Turning** | 0.3 с: уши дёргаются, пузырь `Hmm?`, поворот головы | **Телеграф.** Подозрение ещё не растёт. Успел отпустить SPACE — чист |
| **Watching** | Лицом к классу, глаза бегают по рядам, взгляд на игрока | Длится `LookDuration`. Наклон под взглядом = `+35/с` подозрения |
| **Staring** | Глаза узкие, наклон вперёд, красный виньет | Если Watching закончился, а игрок всё ещё наклонён — не отворачивается, пока игрок не отпустит SPACE + 0.5 с. Только с фазы 3 |
| **Alerted** | Резкий разворот `What was that?!` | Вызывается треском карандаша (с фазы 3) или мяу (шанс `MeowAlert`). Ведёт в Watching |
| **Distracted** | Уходит к утке, спина к игроку | Бросок утки, 4.0 с. Любые проверки отменены |

Правила:
- После Watching/Staring всегда возвращается в Writing и планирует следующий `CheckDelay = random(min, max)` по фазе.
- Пока игрок **не наклонён**, взгляд учительницы ничего не делает (даже если лапа соседа поднята).
- **Almost caught** +1: учительница вошла в Watching, когда игрок был наклонён (для звёзд).
- Реплики (пузырь над головой, 1.2 с): §13.3.

## 10. Подозрение (Suspicion)

Шкала 0–100, HUD под учительницей. `≥100` → **CAUGHT**.

| Событие | Изменение |
|---|---|
| Наклон под взглядом (Watching/Staring) | `+35 / с` (смерть с нуля за ~2.9 с) |
| Ошибка ввода (треск карандаша) | `+8` |
| Мяу, когда учительница уже смотрит | `+15` |
| Не наклонён **и** на тебя не смотрят | `−5 / с` (пассивное остывание) |
| Бросок утки | `−20` |
| Верный ответ | `0` (не награда, а норма) |

Цветовая зонa шкалы: 0–50 жёлтый, 50–80 оранжевый, 80+ красный + пульс + сердцебиение в звуке.

### 10.1 Резиновая утка

**Фикция:** «Emotional support duck. Permitted during exams.» — единственная легальная вещь на парте, и это официально написано мелким шрифтом на доске под правилами.
**Механика — БРОСОК‑ОТВЛЕЧЕНИЕ (decoy):**
1. `Q`/клик → котёнок швыряет утку через класс. Утка летит по дуге 0.6 с, приземляется у доски с громким **SQUEAK**. Класс ржёт.
2. Учительница: `WHOSE DUCK IS THIS?!` → состояние **Distracted 4.0 с**: идёт к утке спиной к игроку, все проверки отменены. Подозрение `−20`.
3. Затем несёт утку обратно и ставит на парту игрока (`Keep. It. Quiet.`) — **утки нет на парте ещё ~8 с** (это диегетический кулдаун, всего ~12 с недоступности). Пока утки нет — бросать нечего.
4. **Третий бросок — конфискация.** `That's it. The duck is MINE.` Утка до конца попытки стоит на учительском столе и грустно смотрит. Больше бросков нет.
5. Использование хотя бы одной утки лишает 3 звёзд (§12).

**Аффорданс (чтобы было видно, что на утку можно нажать):** утка на парте покачивается (idle bob), при наведении — увеличивается на 10 %, курсор — рука, под ней кейкап **`Q`**, а на паузе перед первым броском (фаза 2) появляется подсказка `Throw the duck when it gets hot`.

## 11. Кривая сложности

Экзамен — **12 вопросов**, 5 фаз. Игра длится до CAUGHT, звонка или 12‑го ответа. Параметры берутся из таблицы по индексу вопроса.

| Фаза | Вопросы | `CheckDelay` (с) | `LookDuration` (с) | `MeowAlert` | Треск → разворот | Staring | `PawWindow` (с) | Strokes / Word | Типы |
|---|---|---|---|---|---|---|---|---|---|
| 1 Tutorial | Q1–Q3 | никогда | — | 0 % | нет | нет | 10 | 2, 3, 3 / — | Strokes |
| 2 Warm‑up | Q4–Q5 | 4.5–6.5 | 1.2–1.8 | 0 % | нет | нет | 7 | 3 / — | Strokes, Pick |
| 3 Attention | Q6–Q8 | 3.0–4.5 | 1.5–2.0 | 35 % | да | да | 5 | 4 / 4 букв | все |
| 4 Pressure | Q9–Q10 | 2.0–3.0 | 1.5–2.5 | 60 % | да | да | 4 | 5 / 5 букв | все |
| 5 Final | Q11–Q12 | 1.5–2.2 | 2.0–2.5 | 90 % | да | да | 3 | 6 / 6 букв | все |

**Как это ощущается по попыткам (цель):**
- Попытка 1: игрок учится мяукать и наклоняться, впервые видит разворот на Q4, умирает на Q5–Q6 (или проигрывает звонку).
- Попытки 2–3: понимает телеграф `Hmm?`, доходит до Q6–Q8, впервые ловит `Did someone MEOW?` и понимает, что мяу — риск.
- Попытка 4+: челлендж. Q9–Q11. Утка используется осознанно. 12/12 — редкое достижение (`EXAM PASSED`).

**Обучение в фазе 1 (контекстные подсказки над партой, исчезают после выполнения):**
1. `MEOW into your mic to get Whiskerstein's attention!` (мигает метр) → после первого мяу
2. `Hold SPACE to lean over` → после первого наклона
3. `Copy the strokes: ← ↑ →` → после первого ответа
4. На Q4 перед первым разворотом: `Psst. She turns around sometimes. Let go of SPACE!`
5. На Q6, когда утка впервые полезна: `Throw the duck when it gets hot [Q]`

### 11.1 Звонок (таймер)
- Экзамен длится **120 с**. Часы на стене всегда видны, но спокойные (ambient).
- На **45 с** до конца учительница объявляет `Ten minutes left, class!`, часы становятся красными и тикают. Это «момент, когда добавился таймер».
- Последние 10 с — громкое тиканье. `0:00` → **BELL RANG**, экзамен окончен с текущим числом ответов.

### 11.2 Бюджет времени (проверка)
Средняя цена вопроса по фазам ≈ 5 / 7 / 8 / 9 / 10 с → 15 + 14 + 24 + 18 + 20 = **91 с** при идеальной игре из 120 с. 12/12 достижимо только мастером — так и задумано.

## 12. Результат, оценка, лидерборд

**Report Card** (табель) открывается при CAUGHT / BELL RANG / EXAM PASSED.

Заголовок: `CAUGHT 😾` / `BELL RANG 🔔` / `EXAM PASSED!`
Статы: `Answers copied N/12` · `Time 1:23` · `Meows` · `Almost caught` · `Ducks thrown`

**Оценка (grade) по числу ответов** — штамп на табеле:

| Ответов | Grade | Сообщение |
|---|---|---|
| 0–2 | **F** | `Detention. Even the duck is disappointed.` |
| 3–5 | **D** | `You cheated like a dog. Cats do better.` |
| 6–8 | **C** | `Average copycat. Whiskerstein noticed.` |
| 9–10 | **B** | `Solid cheating. Barely any paw prints.` |
| 11 | **A** | `Almost purrfect. The bell saved her, not you.` |
| 12 | **A+** + звёзды | см. ниже |

**Звёзды только при 12/12:** ★★★ — 0 уток и ≤1 almost caught (`Purrfect crime. No duck, no evidence.`); ★★☆ — ≤3 almost caught (`Nice cheating. A few close calls.`); ★☆☆ — иначе (`Passed by a whisker.`).

**Лидерборд (Google Sheets):**
- Строка: `name, answers, timeSeconds, grade, dateUtc`. Время — сколько секунд шёл экзамен до конца попытки.
- Сортировка: `answers` по убыванию, затем `timeSeconds` по возрастанию (быстрее набрал столько же — выше).
- Показываем топ‑10 и строку игрока с рангом (`#37 — you`). Своя строка подсвечена.
- Отправка после каждой попытки. Нет сети/таймаут 5 с → `Leaderboard offline` и локальный лучший результат.

Кнопки: `RETAKE EXAM` (сразу в геймплей, без интро) · `MAIN MENU`.

## 13. Контент

### 13.1 Вопросы (12)
Вопрос печатается на своём листе одной строкой (≤ 9 слов). Тип и сосед фиксированы. `Payload` — что показывает сосед.

| # | Фаза | Тип | Сосед | Вопрос (на своём листе) | Payload (на листе соседа) |
|---|---|---|---|---|---|
| 1 | 1 | Strokes | L | How many lives does a cat claim to have? | `↑ →` |
| 2 | 1 | Strokes | L | Complete: cat + cardboard box = ? | `← ↑ →` |
| 3 | 1 | Strokes | L | Who discovered gravity by knocking a cup off? | `↓ → ↑` |
| 4 | 2 | Pick | R | Best time for zoomies? | A 3 AM ✓ · B Noon · C Never · D Tuesday |
| 5 | 2 | Strokes | L | Translate 'pspspsps' into Cat Latin. | `↑ ← ↓` |
| 6 | 3 | Word | R | What sings outside at 5 AM? | `BIRD` |
| 7 | 3 | Strokes | L | Optimal nap-to-chaos ratio? | `↓ ← ↑ →` |
| 8 | 3 | Pick | R | Why is the laser dot impossible to catch? | A Physics · B Betrayal ✓ · C Lag · D Magic |
| 9 | 4 | Strokes | L | Define cardboard-box quantum mechanics. | `← ↑ → ↓ ←` |
| 10 | 4 | Word | R | The sound of a happy cat? | `PURRS` |
| 11 | 5 | Word | L | Forbidden green plant of joy? | `CATNIP` |
| 12 | 5 | Strokes | R | Did you CATegorically avoid cheating? | `← → ↑ ↓ ← ↑` — на своём листе печатается `Answer: NO` |

Правила контента: слова без `M` и `Q`, длина строго по фазе; у Pick варианты — 1–3 слова; вопрос ≤ 9 слов.
Коля финализирует формулировки (задача G1), но структура (тип/сосед/длина) фиксирована балансом.

**Банк слов (без M/Q):** 4 — `TUNA BIRD FISH YARN HISS PAWS NAPS`; 5 — `PURRS LASER TREAT KNOCK SOFAS`; 6 — `CATNIP KNOCKS HAIRDO`.

## 14. Интро (лор)

Формат — **комикс из 5 статичных панелей** с медленным наездом камеры (Ken Burns), субтитрами и озвучкой. Не видео (см. решение D‑07 в `PROJECT.md`).
Общая длина ~25 с, любая панель пропускается кликом, всё интро — Esc.

Озвучка учительницы: «оригинал» — кошачья речь `Meow meow meow. Meow. MEOW.` (TTS, ускоренный), поверх — гундосый украинский дубляж (TTS `Lesya`, полосовой фильтр «телефон»), как в старых VHS‑переводах. Субтитры — английские.

## 15. UI/HUD (раскладка 1920×1080)

- **Верх:** слева логотип‑чип `COPYCAT`, центр `ANSWERS 7 / 12`, справа часы на стене (часть фона, цифры поверх).
- **Центр‑верх:** доска с правилами, перед ней учительница. Под ней шкала `SUSPICION`.
- **Средний план:** парты соседей слева и справа под углом (перспектива), их листы, лапы, кольца‑таймеры.
- **Низ (своя парта, трапеция):** свой лист по центру, лапы котёнка, утка справа с кейкапом `Q`, метр `MEOW` (круг с заливкой и красной линией порога) слева над партой.
- **Виньет опасности:** оранжевый — учительница смотрит; красный пульс — смотрит, а ты наклонён.
- **Флеши:** слева, чтобы не перекрывать учительницу и её пузырь.

Полный список экранов: Main Menu, Attendance Sheet, Intro, HUD, Report Card, Loading, Error (из шаблона).

## 16. Аудио

SFX: мяу‑фолбэк ×3, писк утки, свист броска, шлепок приземления, смех класса, треск карандаша, скрип карандаша при вводе, штамп COPIED, скрип мела, вздох «Hmm?», сердцебиение (80 %+), тиканье, звонок, шаги учительницы.
Музыка: тихий напряжённый эмбиент «класс» с тиканьем, ускоряется на последних 45 с. Громкость музыки авто‑приглушается при активном микрофоне (чтобы не триггерить сам себя через колонки: игрок в наушниках не обязателен, поэтому музыка тихая, −18 dB).
VO: только интро.

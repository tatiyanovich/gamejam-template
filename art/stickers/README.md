# COPYCAT presentation stickers

Eight standalone PNG stickers generated for slide layouts. Every file has a real transparent alpha channel and keeps generous padding for rotation, overlap, and drop-shadow effects in presentation software.

## Files

- `kitten_caught_cheating.png` — panicked orange kitten hiding an exam note
- `duck_flying.png` — emotional-support duck in chaotic flight
- `teacher_accusing.png` — Mrs. Hisskins pointing at the viewer
- `whiskerstein_a_plus.png` — Whiskerstein showing an A+ paper
- `fluffy_sleeping.png` — sleepy Fluffy over an exam sheet
- `duck_confiscated.png` — sad confiscated duck in red glasses
- `copied_stamp.png` — green `COPIED!` stamp with a check mark
- `exam_combo.png` — exam paper, pencil, and arrow combo

## Generation notes

Generated with the built-in image-generation tool using the project sheets in `art/previews/d1`, `d3`–`d8` as visual references. The shared prompt requested COPYCAT's chunky hand-drawn forms, dark-brown rounded outline (`#2A1F1A`), flat project palette, simple internal shadow, isolated composition, and a genuinely transparent background. Each asset then received its subject-specific pose and props described above.

These are presentation assets, not Unity runtime sprites. Original generated files remain in the Codex generated-images cache; the copies in this folder are the project deliverables.
